# cc-connect-next v0.1.1-beta.1

## 中文

这是 `v0.1.0` 正式稳定版之后、基于最新 `main` 的首个 beta。此次版本把最近合入主线的更新入口、额度错误提示和飞书状态卡修复一起交付。

### 变化

- **统一稳定版更新入口。** `cc-connect-next update` 会自动识别 npm 全局安装与独立二进制安装，只选择 GitHub 上的稳定版；npm 安装更新到精确的稳定版包，独立二进制更新会校验 `checksums.txt`，并在替换失败时保留回滚路径。
- **明确的额度耗尽卡片。** Codex 使用额度耗尽时展示专用、经过本地化且不泄露敏感信息的失败卡片，不再退化成含糊的通用失败提示。
- **去掉思考卡和工具调用卡的重复正文首行。** 保留卡片 Header、匿名进度计数、隐私边界和状态切换，正文不再重复“正在思考”或“正在调用工具”。
- **发布链路继续按版本 tag 验证。** npm 包和 GitHub Release 使用同一个版本号与对应的发布资产。

### 升级

beta 用户需要显式选择 beta 通道：

```bash
npm install -g cc-connect-next@beta
```

独立二进制用户可从本版本的 GitHub Release 下载对应平台资产。`cc-connect-next update` 只更新稳定版，不会把稳定安装自动切换到 beta。

## English

This is the first beta after the `v0.1.0` stable release, built from the latest
`main`. It delivers the unified updater, the Codex usage-limit card, and the
recent Feishu lifecycle-card copy fix together.

### Changes

- **One stable-only update entry point.** `cc-connect-next update` detects npm global installations and standalone binaries, and selects stable GitHub releases only. npm installations update to the exact stable package version; standalone updates verify `checksums.txt` and retain a rollback path if replacement fails.
- **A dedicated usage-limit card.** Codex allowance exhaustion now produces a localized failure card without sensitive details instead of the ambiguous generic failure message.
- **No duplicated first line in thinking and tool cards.** Card headers, anonymous progress counts, privacy boundaries, and lifecycle transitions remain unchanged, while the body no longer repeats “thinking” or “calling tools”.
- **Tag-bound release verification.** The npm package and GitHub Release use the same version and matching release assets.

### Upgrade

Beta users must opt into the beta channel explicitly:

```bash
npm install -g cc-connect-next@beta
```

Standalone users can download the matching platform asset from this beta's
GitHub Release. `cc-connect-next update` remains stable-only and will not move
a stable installation onto the beta channel automatically.
