## v1.5.1-beta.1 — 2026-08-28

Beta release since v1.5.0 stable. 17 commits / 16 merged PRs across Feishu, Weixin, Claude Code, Codex, Pi, session, daemon, and skills.

### Features
- **i18n** - Localize agent system prompts (cron/timer/send/relay) based on language config (#1721, #1655)
- **Cursor** - Deliver image attachments to the Cursor CLI via on-disk paths (#1709)

### Bug Fixes
- **Feishu** - Chunked HTTP Range download for large resources, bypassing code=234037 (#1746); fail-closed when bot open_id discovery fails at startup (#1725)
- **Weixin** - Split send budget by reply vs push path (#1743); configurable inbound message dedup (#1733)
- **Claude Code** - Drop `--replay-user-messages` so `/compact` and slash commands stay reachable (#1737); bounded session teardown with WaitDelay / kill retry / close-spawn race guard (#1714)
- **Codex** - Propagate failed app-server turns (#1730); support max reasoning effort (#1727); `/list` correctly reads session names (#1639)
- **Pi** - Pass attachments as `@<path>` argv refs instead of inlining bytes (#1724); remove unused `os` import breaking Windows builds (#1738); keep turn open while Pi auto-retries transient errors (#1597)
- **Session** - Keep `/switch` target exempt from immediate idle reset (#1734)
- **Daemon** - Drop redundant CheckLinger stub breaking non-Linux builds (#1710)
- **Skills** - Include plugin skill roots safely (#1713)
- **WeCom** - Preserve quoted messages as agent context (#1669)
- **Web** - Validate project work_dir (#1572)
- **Kimi** - Native Kimi Code CLI dialect support (#1564)
