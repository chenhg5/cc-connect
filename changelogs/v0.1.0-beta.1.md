# cc-connect-next v0.1.0-beta.1

## 中文

这是 cc-connect-next 的首个公开 Beta。它以官方 CC Connect v1.4.1 为历史基线，但作为独立后继项目安装、运行和升级，不覆盖官方二进制、配置目录或 daemon。

### 重点变化

- 飞书 Card 2.0 单卡生命周期：首卡即时反馈、正文持续更新、工具与推理仅显示不可展开的聚合进度，结束时明确完成或失败。
- 对一次性返回完整正文的 Agent 事件保留可感知的“正在回答”窗口，避免 CardKit 打字机帧被紧随其后的完成卡直接覆盖；真正增量输出的回答不会额外等待。
- 保留原始消息引用关系、完成表情和文件引用优化，同时隐藏推理正文、工具参数、Shell 内容及冗余模型/token/工作目录尾巴；即使 Agent 尾巴被拆成多个流式事件，也不会短暂进入卡片，形似尾巴但随后继续的正常正文仍会保留。
- 显式迁移命令覆盖配置、有效 `data_dir`、会话、项目状态、cron/timer、workspace bindings 和项目内图片/附件，并生成逐文件 SHA-256 manifest 与可恢复备份。
- 迁移兼容官方 v1.4.1、v1.5.0-beta.1、beta.2 和 beta.3 的已知持久化布局；TOML schema、正常启动语义和 Agent/平台可用性会在写入前完整校验，无效展示模式、缺失 Agent/平台或当前构建不支持的行为都会安全失败。
- npm 安装器在解压前验证 GitHub Release 的 `checksums.txt`，六个平台归档由同一标签流水线构建并校验。
- 修复非管理员可通过 `addexec` 注册 Shell 命令，以及 Codex app-server 写入阻塞时无法按时退出的问题。

### 升级与迁移

```bash
npm install -g cc-connect-next@beta
cc-connect-next migrate --dry-run
cc-connect-next migrate
```

官方 CC Connect 与 Next 可以同时安装，但不要让两者使用同一飞书应用凭证同时建立连接。正式切换前请停止官方实例并执行一次最终 `migrate --force` 同步。

## English

This is the first public beta of cc-connect-next. It preserves official CC Connect v1.4.1 history while installing, running, and upgrading as an independent successor without overwriting the official binary, data directory, or daemon.

### Highlights

- A single Feishu Card 2.0 lifecycle with immediate acknowledgement, continuously updated answer text, non-expandable aggregate reasoning/tool progress, and explicit terminal status.
- A perceptible answering window for Agent backends that emit the whole answer in one event, preventing the CardKit typewriter frame from being overwritten immediately by Done without delaying naturally incremental streams.
- Quoted reply context, completion reactions, and readable file references without exposing reasoning text, tool arguments, shell content, or model/token/work-directory footers. Fragmented footer events never enter an intermediate card, while footer-shaped prose is preserved when later text proves it is not a complete footer line.
- An explicit migration command for config, effective `data_dir`, sessions, project state, cron/timers, workspace bindings, and project-local media, with per-file SHA-256 manifests and recoverable backups.
- Known persistent-layout compatibility for official v1.4.1 and v1.5.0-beta.1 through beta.3. TOML schema, normal startup semantics, and Agent/platform availability are all checked before writes; invalid display modes, missing Agent/platform entries, and unsupported behavior fail closed.
- The npm installer verifies the GitHub Release `checksums.txt` before extraction; all six platform archives are built and checked from the same tag workflow.
- Security and reliability fixes for non-admin `addexec` registration and blocked Codex app-server writes.

### Install and migrate

```bash
npm install -g cc-connect-next@beta
cc-connect-next migrate --dry-run
cc-connect-next migrate
```

Official CC Connect and Next may remain installed together, but they must not connect concurrently with the same Feishu app credentials. Stop the official instance and run a final `migrate --force` synchronization before production cutover.
