# cc-connect-next v0.1.0-beta.2

## 中文

这是 cc-connect-next 的第二个公开 Beta，基于 `v0.1.0-beta.1` 继续完善飞书能力和迁移后的首次使用体验。

### 变化

- 吸收并重新适配官方 CC Connect 在原始分叉点之后合并的飞书能力：话题级工作区绑定、已有话题首次 @ 的根上下文补入、带隐私门禁的引用文件下载、话题内 Relay 可见性，以及显式的机器人间 `mention_map`。
- 新增 `group_reply_all_chats`：可以用逗号分隔的 chat ID 字符串或 TOML 字符串数组指定免 @ 群聊。指定群聊不需要 @ 机器人，未列出的群聊继续沿用必须 @ 的默认行为。
- 对 `group_reply_all_chats` 做严格输入校验并在配置示例、飞书文档和回归测试中说明；飞书仍需要发布 `im:message.group_msg` 敏感权限，平台才会推送未 @ 的群消息。

### 修复

- 修复从空配置执行 `feishu new` 时项目索引为 `-1` 导致的 onboarding panic。
- 增加空文件、空白文件和按群路由的回归测试，并让路由测试不再依赖假凭证触发的飞书名称查询。

### 升级

```bash
npm install -g cc-connect-next@beta
```

现有 `v0.1.0-beta.1` 用户可以直接升级；官方 CC Connect 的二进制、配置目录、daemon 和飞书连接不会被本项目覆盖。

## English

The second public beta continues the Feishu parity work and hardens first-run onboarding after migration from official CC Connect.

### Changes

- Re-adapt the Feishu capabilities merged upstream after the original fork point: topic-scoped workspace bindings, first-mention root-context bootstrap for existing topics, privacy-gated quoted-file downloads, topic-local Relay visibility, and explicit bot-to-bot `mention_map`.
- Add `group_reply_all_chats`, accepting either a comma-separated chat-ID string or a TOML string array. Listed chats accept unmentioned group messages; all other groups keep the explicit-mention requirement.
- Validate the allowlist strictly and document it in the example config and Feishu guide. Feishu still requires the published sensitive `im:message.group_msg` permission before unmentioned group events are delivered.

### Fixes

- Prevent `feishu new` from indexing project `-1` and panicking when onboarding starts from an empty configuration.
- Add regression coverage for empty/whitespace-only configs and per-chat routing, with the routing test isolated from fake-credential name lookups.

### Upgrade

```bash
npm install -g cc-connect-next@beta
```

Existing `v0.1.0-beta.1` installations can upgrade in place. The official CC Connect binary, data directory, daemon, and Feishu connection are not overwritten by this project.
