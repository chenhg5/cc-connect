# Feishu: ответы без упоминания в группе с одним участником

[Руководство по подключению Feishu](feishu.md) · [简体中文](feishu-solo-chat.md) · [English](feishu-solo-chat.en.md)

Включите параметр в разделе `[projects.platforms.options]` соответствующей платформы Feishu:

```toml
solo_chat_reply_all = true  # по умолчанию: false
```

Параметр действует только в группах, где, по данным Feishu, ровно один человек и один бот. Сообщение без упоминаний может вызвать ответ бота; упоминание только другого участника не считается поводом для ответа. Для чтения сведений о группе требуется `im:chat:readonly`. Для получения групповых сообщений без упоминания бота нужно предоставить и опубликовать разрешение `im:message.group_msg`. Остальные правила маршрутизации групповых сообщений не меняются.

- Новый запрос состава группы выполняется только после проверок `allow_chat` и `allow_from`. Если идентификатор бота неизвестен или запрос не удался, исключение для сообщений без упоминаний не действует.
- Первый запрос ожидается до 5 секунд. После ошибки повторный запрос возможен через 5 секунд. Для каждой группы одновременно выполняется только один запрос. Поступившие в это время сообщения без упоминаний не запускают бота, если состав группы ещё неизвестен, и не обрабатываются повторно.
- Результаты успешных запросов, в том числе для групп, которые не отвечают условиям, кешируются на 30 секунд. После изменения состава группы некоторое время может использоваться прежний результат.
- Если включена изоляция тем и задано `attachment_wait = "mention"`, пропуск сообщения только по этому параметру не запускает и не продлевает ожидание вложений и не отправляет отложенные вложения. Подходящие вложения без упоминания по-прежнему откладываются по правилам темы.
