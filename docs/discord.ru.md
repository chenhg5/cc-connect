# Руководство по настройке Discord

[English](discord.md) | Русский

Это руководство поможет подключить **cc-connect** к Discord, чтобы общаться с локальным Claude Code через Discord-бота.

## Предварительные требования

- Учётная запись Discord
- Компьютер, на котором можно запустить cc-connect (публичный IP-адрес не нужен)
- Установленный и настроенный Claude Code

> 💡 **Преимущество**: используется Gateway (WebSocket) — публичный IP-адрес, домен и обратный прокси не нужны.

---

## Шаг 1. Создайте приложение Discord

### 1.1 Откройте портал разработчика

Перейдите на [портал разработчика Discord (Discord Developer Portal)](https://discord.com/developers/applications) и войдите в свою учётную запись.

### 1.2 Создайте новое приложение

1. Нажмите «New Application» (новое приложение) в правом верхнем углу
2. Введите имя приложения (например, `cc-connect`)
3. Примите условия использования (Terms of Service)
4. Нажмите «Create» (создать)

---

## Шаг 2. Создайте учётную запись бота

### 2.1 Перейдите к настройкам бота

В боковом меню слева нажмите «Bot» (бот).

### 2.2 Добавьте бота

1. Нажмите «Add Bot» (добавить бота)
2. Подтвердите действие

### 2.3 Настройте профиль бота

| Поле | Рекомендуемое значение |
|-------|----------------|
| Username (имя пользователя) | `cc-connect` |
| Avatar (аватар) | Загрузите понравившийся значок |

---

## Шаг 3. Получите токен бота

### 3.1 Создайте токен

На странице «Bot» (бот):

1. Нажмите «Reset Token» (сбросить токен)
2. При необходимости введите код двухфакторной аутентификации (2FA)
3. Нажмите «Copy» (копировать), чтобы скопировать токен

> ⚠️ Токен показывается только один раз — сразу сохраните его и никому не раскрывайте! Формат: `MTk4NjIyNDgzNDcOTY3NDUxMg.G8vKqh.xxx...`

### 3.2 Потеряли токен?

Вы можете в любой момент нажать «Reset Token» (сбросить токен), чтобы создать новый. Старый токен сразу перестанет действовать.

---

## Шаг 4. Настройте привилегированные Intents (важно!)

### 4.1 Что такое Intents?

Intents определяют, какие события бот может получать через Discord Gateway.

### 4.2 Включите необходимые Intents

На странице «Bot» (бот) в разделе «Privileged Gateway Intents» (привилегированные Intents шлюза) включите:

| Intent | Назначение | Обязателен? |
|--------|---------|-----------|
| **Message Content Intent** (доступ к содержимому сообщений) | Чтение содержимого сообщений | ✅ **Обязателен** |
| Presence Intent (доступ к статусам пользователей) | Чтение статуса пользователя | Необязателен |
| Server Members Intent (доступ к участникам сервера) | Получение сведений об участниках сервера | Необязателен |

> ⚠️ **Обязательно включите Message Content Intent**, иначе бот не сможет читать сообщения!

### 4.3 Сохраните изменения

Нажмите «Save Changes» (сохранить изменения).

---

## Шаг 5. Настройте cc-connect

Добавьте токен в `config.toml`:

```toml
[[projects]]
name = "my-project"

[projects.agent]
type = "claudecode"

[projects.agent.options]
work_dir = "/path/to/your/project"
mode = "default"

[[projects.platforms]]
type = "discord"

[projects.platforms.options]
token = "MTk4NjIyNDgzNDcOTY3NDUxMg.G8vKqh.xxx..."
# thread_isolation = true  # Optional: isolate each agent session in its own Discord thread
# progress_style = "legacy" # Optional: legacy | compact | card
```

> cc-connect автоматически настраивает необходимые Intents (MESSAGE_CONTENT, GUILD_MESSAGES, DIRECT_MESSAGES).
> При `thread_isolation = true` cc-connect создаёт или повторно использует ветку Discord для каждой сессии и направляет последующие сообщения по ID канала ветки.
> `progress_style = "compact"` объединяет сообщения о ходе рассуждений и работе инструментов в одно редактируемое сообщение; `progress_style = "card"` отображает ход работы во встроенной карточке Discord (embed), а итоговый ответ по-прежнему отправляет обычным сообщением.

---

## Шаг 6. Создайте ссылку-приглашение

### 6.1 Перейдите к настройкам OAuth2

В боковом меню слева нажмите «OAuth2» → «URL Generator» (генератор URL).

### 6.2 Выберите области доступа

В разделе «Scopes» (области доступа) отметьте:

- ✅ `bot`

### 6.3 Выберите разрешения

В разделе «Bot Permissions» (разрешения бота) отметьте:

| Разрешение | Назначение |
|------------|---------|
| Read Messages/View Channels (читать сообщения / просматривать каналы) | Чтение сообщений |
| Send Messages (отправлять сообщения) | Отправка сообщений |
| Create Public Threads (создавать публичные ветки) | Создание новой ветки для новой сессии агента |
| Send Messages in Threads (отправлять сообщения в ветках) | Отправка сообщений в ветках |
| Read Message History (читать историю сообщений) | Чтение истории сообщений |

### 6.4 Скопируйте ссылку

1. Ссылка-приглашение появится внизу страницы
2. Нажмите «Copy» (копировать)

---

## Шаг 7. Пригласите бота на свой сервер

### 7.1 Откройте ссылку-приглашение

Откройте скопированный URL в браузере и войдите в Discord.

### 7.2 Выберите сервер

В раскрывающемся списке выберите сервер, на который хотите добавить бота.

### 7.3 Предоставьте доступ

Проверьте разрешения и нажмите «Authorize» (авторизовать). При необходимости пройдите CAPTCHA.

---

## Шаг 8. Запустите cc-connect

### 8.1 Запуск

```bash
cc-connect
# Or specify a config file
cc-connect -config /path/to/config.toml
```

### 8.2 Проверьте подключение

В журнале должны появиться примерно такие записи:

```
level=INFO msg="discord: connected" bot=cc-connect#0000
level=INFO msg="platform started" project=my-project platform=discord
level=INFO msg="cc-connect is running" projects=1
```

---

## Шаг 9. Начните общение

### 9.1 Общение в канале

Отправьте сообщение в любой канал, где у бота есть необходимые разрешения.

### 9.2 Личные сообщения

1. Нажмите на аватар бота
2. Отправьте личное сообщение (DM)

---

## Пример использования

```
User: Help me analyze the current project structure

cc-connect: 🤔 Thinking...
cc-connect: 🔧 Tool: Bash(ls -la)
cc-connect: Here's the project structure...
```

Если включить `progress_style = "card"`, во время обработки запроса Discord показывает одну редактируемую карточку (embed) с ходом работы, а итоговый ответ приходит отдельным обычным сообщением. Это уменьшает количество служебных сообщений в канале по сравнению с прежним режимом, в котором отправлялось несколько сообщений.

## Особенности Discord Gateway

| Характеристика | Описание |
|---------|---------|
| **Подключение** | WebSocket |
| **Публичный IP-адрес** | ❌ Не нужен |
| **Heartbeat** (проверка активности соединения) | Автоматическое поддержание соединения |
| **Повторное подключение** | Автоматически при разрыве соединения |
| **Intents** | Необходимо объявить нужные типы событий |
| **Ограничение длины сообщений** | 2000 символов на сообщение (cc-connect автоматически разбивает длинные сообщения) |
| **Markdown** | Полная встроенная поддержка |

## Частые вопросы

### Бот не может прочитать содержимое сообщений?

**Самая частая причина**: не включён Message Content Intent!

Как исправить:

1. Откройте Discord Developer Portal
2. Выберите приложение → «Bot» (бот)
3. Включите «Message Content Intent» (доступ к содержимому сообщений)
4. Сохраните изменения
5. Перезапустите cc-connect

### Бот подключается и сразу отключается?

Проверьте:

1. Правильно ли указан токен бота?
2. Правильно ли настроены Intents?
3. Не превышены ли ограничения Discord на частоту запросов из-за частых повторных подключений?

### Бот не появляется на сервере?

1. Убедитесь, что добавили бота по ссылке-приглашению
2. Проверьте, не был ли бот исключён с сервера

### Как создать новый токен?

1. Откройте Discord Developer Portal
2. Выберите приложение → «Bot» (бот)
3. Нажмите «Reset Token» (сбросить токен)
4. Обновите config.toml

### У бота недостаточно прав?

1. Создайте новую ссылку-приглашение с нужными разрешениями
2. Повторно пригласите бота на сервер
