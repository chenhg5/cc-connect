# 飞书单人群免 @

在对应飞书平台的 `[projects.platforms.options]` 里启用：

```toml
solo_chat_reply_all = true  # 默认 false
```

该选项仅在飞书报告群内恰好一人和一个机器人时生效。不 @ 任何人的消息可以触发机器人；只 @ 其他人的消息不会因此触发。读取群信息需要 `im:chat:readonly`，接收未 @ 的群消息需要 `im:message.group_msg`。此选项不覆盖其他已配置的群路由规则。

- 只有通过 `allow_chat` 和 `allow_from` 才会进行新成员查询。机器人身份未知或群成员信息读取失败时，不启用免 @ 例外。
- 首次查询同步等待，超时为 5 秒；失败后冷却 5 秒再试。同一群只允许一次查询在途，其他成员状态未知的未提及消息不会因此触发，也不会在查询完成后重放。
- 成功结果（包括非单人群）缓存 30 秒。成员加入、离开或增加机器人后，判定可能暂时沿用旧值。
- 启用话题隔离和 `attachment_wait = "mention"` 时，仅因单人群模式放行的消息不会激活、延长或释放附件暂存。未 @ 的可暂存附件遵循原有话题规则。
